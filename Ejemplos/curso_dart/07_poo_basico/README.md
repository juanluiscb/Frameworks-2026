# Módulo 7: Programación Orientada a Objetos (POO)

Dart es un lenguaje orientado a objetos, lo que significa que usamos clases para modelar el mundo real.

## Clases y Objetos
- **Clase**: El "molde" o plano para crear algo (ej. Persona).
- **Objeto**: La instancia creada a partir del molde (ej. Juan).
- **Atributos**: Características de la clase (nombre, edad).
- **Métodos**: Acciones que puede realizar la clase (caminar, hablar).
- **Constructor**: Función especial que se ejecuta al crear el objeto.

## Ejemplo de Constructor Corto
Dart permite asignar valores directamente en el constructor:
```dart
Persona(this.nombre, this.edad);
```

## Ejecución
```bash
dart run main.dart
```

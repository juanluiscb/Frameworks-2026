# Módulo 1: Hola Mundo en Dart

Bienvenido al curso de Dart. En este primer paso, aprenderemos lo más básico: cómo imprimir texto en la consola y cuál es la estructura mínima de un programa en Dart.

## Conceptos Clave
- **Función `main()`**: Es el punto de entrada de cualquier aplicación Dart. Todo el código que quieras ejecutar al inicio debe estar dentro de esta función.
- **`print()`**: Una función que muestra información en la consola.
- **Punto y coma `;`**: En Dart, es obligatorio terminar las sentencias con punto y coma.

## Paso a Paso
1. Define la función `void main() { ... }`.
2. Dentro de las llaves, usa `print('Tu mensaje aquí');`.
3. Guarda el archivo como `main.dart`.

## Ejecución
Para ejecutar este código, abre una terminal en esta carpeta y escribe:
```bash
dart run main.dart
```

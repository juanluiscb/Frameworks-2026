# Curso Completo de Dart para Principiantes 🚀

Este curso está diseñado para llevarte desde los conceptos más básicos de Dart hasta temas más avanzados como la asincronía y la programación orientada a objetos.

## 📁 Estructura del Curso

Cada carpeta contiene un archivo `README.md` con la teoría y un archivo `main.dart` con el código práctico.

1.  **[01 Hola Mundo](./01_hola_mundo/)**: Estructura básica de un programa.
2.  **[02 Variables y Tipos](./02_variables_tipos/)**: Manejo de datos y tipos básicos.
3.  **[03 Operadores](./03_operadores/)**: Cálculos y lógica.
4.  **[04 Control de Flujo](./04_control_flujo/)**: Decisiones y bucles.
5.  **[05 Funciones](./05_funciones/)**: Reutilización de código y parámetros.
6.  **[06 Colecciones](./06_colecciones/)**: Listas, Sets y Mapas.
7.  **[07 POO Básico](./07_poo_basico/)**: Introducción a Clases y Objetos.
8.  **[08 Null Safety](./08_null_safety/)**: Programación segura y manejo de nulos.
9.  **[09 Asincronía](./09_asincronia/)**: Manejo de Futures, async y await.
10. **[10 POO Avanzado](./10_poo_avanzado/)**: Herencia, Clases Abstractas y Polimorfismo.

## 🚀 Cómo empezar

1. Navega a la carpeta del módulo que quieras estudiar.
2. Lee el `README.md` para entender la teoría.
3. Ejecuta el código usando el comando:
   ```bash
   dart run main.dart
   ```

¡Disfruta el aprendizaje!

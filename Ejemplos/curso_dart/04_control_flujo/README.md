# Módulo 4: Control de Flujo

Aprenderemos a controlar qué partes del código se ejecutan según ciertas condiciones o repeticiones.

## Sentencias de Decisión
- `if / else`: Evalúa una condición booleana.
- `switch`: Compara un valor contra múltiples casos.

## Bucles (Estructuras de Repetición)
- `for`: Ideal cuando sabes cuántas veces repetir el código.
- `while`: Repite mientras una condición sea verdadera.
- `do-while`: Similar al while, pero garantiza que el código se ejecute al menos una vez.

## Ejecución
```bash
dart run main.dart
```
